## 设计与实现核对

概念稿位于 `docs/design/`，原生尺寸1586×992；实现在1440×900与1280×720检查，同时保存2倍截图。主创作屏保持侧栏、可编辑标题、七模式、脚本/检查器双栏及底部生成栏的构图。

1. 布局：标题、模式、脚本框共用左边界；主操作无需整页滚动。
2. 色彩：浅底、白面板、墨绿强调；去掉原深色发光与渐变。
3. 字体：思源宋体阅读区与标题，系统无衬线控件；本地字体不可用时加载OFL网页子集。
4. 控件：统一40px级高度、8px圆角、同源图标；设置保存列与输入框严格对齐。
5. 信息：删除重复当前工作流、固定假项目名；新建降级至更多菜单。
6. 响应：手机模式换两行，声音设置弹窗展开；模板与作品采用独立内部滚动。

有意差异：概念稿的1000字示意改为真实3000字预检上限；保留原时间戳标签；设置右侧用于真正可运行的本地环境检查；声音上传说明明确发送到阿里云。没有把概念图直接作为页面。先前的 `*-first.png` 属于迭代证据，文章排版请使用上述最终 `@2x` 图片。
